eCW Security Validator

What eCW grants each role, what your master matrix says it should have, and exactly where they differ. Files never leave your browser.

Sample data. These are example files with planted discrepancies, so you can see what the validator does. Drop your own matrix and eCW exports to replace them.

1 · Baseline — what users should have

Your approved permission matrix: settings down, users or roles across, Y/N in the cells — or one row per user + setting. A user → role sheet in the same workbook is used automatically.

Reading options

2 · eCW export — what roles actually have

In eCW: Security Settings → pick a role → Export to Excel. eCW exports one role at a time, so drop one file per role (several at once is fine) and say which role each one is. A per-user list (User | Setting | Value) also works.

Reading options

3 · eCW settings catalog (optional, recommended)

eCW's Security Settings export that lists every setting with its description, type and group (Admin → Security Settings → export; ~1,100 rows, no users). With it, every finding shows the setting's group and what it controls, baseline names eCW does not know are flagged with the closest real name, and you get a coverage view of what the baseline never mentions. Drop it in the wrong slot and it is moved here automatically.
