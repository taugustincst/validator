eCW Security Settings Validator

Compare what eClinicalWorks says each user can do with what your baseline spreadsheet says they should be able to do. Files stay on this machine.

1 · Baseline (what users should have)

Your approved permission matrix: settings down the first column and users (or roles) across, Y/N in the cells — or one row per user and setting. A second sheet mapping user → role is picked up automatically.

Reading options

2 · eCW export (what users actually have)

In eCW: Admin → Security Settings (or Reports → User Security Settings) → Print/Export to Excel. Save as .xlsx or .csv and drop it here.

Reading options

3 · Comparison options

Severity: High = eCW grants access the baseline does not (remove it, or approve it in the baseline). Medium = the baseline requires access eCW lacks, a level mismatch, or a baseline user eCW does not list. Low / Info = coverage gaps between the two documents.
