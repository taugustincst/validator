eCW Security Settings Validator

See what eCW says each user can do, what your baseline says they should be able to do, and exactly where the two differ. Files stay on this machine.

1 · Baseline — what users should have

Your approved permission matrix: settings down, users or roles across, Y/N in the cells — or one row per user + setting. A user → role sheet in the same workbook is used automatically.

Reading options

2 · eCW export — what users actually have

In eCW: Admin → Security Settings (or Reports → User Security Settings) → Print / Export to Excel. Save as .xlsx or .csv and drop it here.

Reading options

3 · Comparison options

High = eCW grants access the baseline does not.Medium = the baseline requires access eCW lacks, a level mismatch, or a baseline user eCW does not list.Low / Info = coverage gaps between the two documents.
