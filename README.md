# Downloads

- **ecw-validator.exe** — Windows x64, standalone (no install). Double-click to open the validator in your browser; the same file is the command line.
- **ecw-validator-windows.zip** — the same file zipped.

Windows SmartScreen may show "Windows protected your PC" the first time because the file is not code-signed: click **More info**, then **Run anyway**.

Built by `npm run build:exe` from the `main` branch.
